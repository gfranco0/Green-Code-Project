# Projeto Extinção Biológica - Green Code Project

## Objetivos
Desenvolver um portal informativo para conscientizar a sociedade sobre a extinção biológica, destacando práticas sustentáveis. Aplicar diretrizes de acessibilidade (WCAG) e captar engajamento do público.

## Tema
Sustentabilidade e Impacto Social: O projeto aborda a crise ambiental da extinção biológica e como a degradação de habitats afeta a segurança alimentar, a saúde pública e os recursos naturais.
